🧭 Pianifica un'uscita di pesca

Confronta le previsioni che consulti su ARPAS, Aeronautica Militare e iLMeteo.it, poi scegli un punto di pesca. I dati delle onde ARPAS sono aggiornati automaticamente quando GitHub Actions è attivo; vento e altre fonti restano manuali.

In attesa del bollettino ARPAS…

ARPAS pubblica Hx (altezza massima dell’onda), non Hs. Un valore ARPAS non va confrontato come se fosse altezza significativa Hs di Open-Meteo. I valori di vento non sono forniti da questo bollettino. Il parere nautico resta prudenziale.

⚠️ ARPAS: aggiornamento automatico disponibile tramite GitHub Actions; altre fonti manuali. I dati ARPAS vengono letti dal file aggiornato nel repository; se il file non è disponibile o è vecchio, viene segnalato. Per i valori automatici già disponibili, usa la scheda Meteo (fonte distinta: Open-Meteo). Non confondere le due previsioni.
